# 物流费用试算器

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 拼车批次台

- 填写线路、发车日、实重、体积；体积重按 220 kg/m³，计费重取实重与体积重较大值。
- 同线路同发车日累计计费重达到整车下限才可拼车；不足时批次保留为候选并显示缺重，不扣返程折扣。
- 返程空车折扣只减基础运费，操作费不参与；已发车批次锁定，订单不得撤回。
- 取消订单使累计跌破下限时，批次自动退回候选并撤销折扣；刷新后候选、批次、折扣与费用保持一致。
- 代码分层：`src/data/`（数据与持久化）、`src/rules/`（计费与批次规则）、`src/stores/`（状态）、`src/components/`（页面）。
